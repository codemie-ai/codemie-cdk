# Quality Gates

Exact commands, grouped by working directory. The repository has no root manifest, so run each block in its package folder. Run only the gates of the package you changed. None of these commands calls the CodeMie platform. CI runs the same steps on `ubuntu-latest` with Node.js 22 (`.github/workflows/ci.yml`).

Status "run" means the command was run on a clean checkout and exited 0.

## Working directory: `iac/codemie-iac-nodejs`

| Gate | Command | Status |
|---|---|---|
| Install | `npm install --no-audit --no-fund` | run |
| Type check | `npx tsc --noEmit` (script: `npm run types:check`) | run |
| Lint | `npx biome lint ./src` (script: `npm run biome:check`) | run |
| Format check | `npx biome format ./src` (script: `npm run format:check`) | run |
| All static checks | `npm run lint` (type check, lint and format check) | run |
| Unit tests | `npm test` | run |
| Build | `npm run build` | run |

Auto-fix scripts: `npm run lint:fix`, `npm run biome`, `npm run format`.

Notes:

- The package has no committed lockfile, so `npm install` resolves dependencies fresh and creates an untracked `package-lock.json`. Do not commit it.
- `npm test` runs `jest --silent --passWithNoTests`. Logs do not show, and a wrong path filter can pass with zero tests. Read the test count.
- Coverage thresholds apply only to `npm run test:ci` and `npm run test:coverage` (not run). CI runs `npm test`.
- `dist/` is generated by `tsup` and has an ignore rule in the package `.gitignore`.

## Working directory: `iac/codemie-iac-python`

| Gate | Command | Status |
|---|---|---|
| Install | `poetry install --no-interaction` | run |
| Lint | `poetry run ruff check .` | run |
| Format check | `poetry run ruff format --check .` | run |
| Unit tests | `poetry run pytest tests/` | run |
| Build | `poetry build` | run |

Auto-fix: `poetry run ruff check --fix .` and `poetry run ruff format .` (not run).

Notes:

- The tests work offline.
- `pyproject.toml` adds rule `C901` (McCabe complexity) with a limit of 15 (`iac/codemie-iac-python/pyproject.toml`, `[tool.ruff.lint]`). Other ruff rules and the format keep their defaults. No type checker runs in CI.
- `poetry build` writes `dist/`, which has no ignore rule. Do not stage it.

## CI-only gates

These gates have no local command. Their workflows live in `codemie-ai/ci-workflows`, outside this repository.

| Gate | Where | Checks |
|---|---|---|
| PR title | `.github/workflows/pr-title-lint.yml` | Conventional Commits format |
| Internal references | `.github/workflows/ci.yml` (job `internal-refs`) | Internal references in the tree |
| Secrets detection | `.github/workflows/ci.yml` (job `secrets-detection`) | Secrets. Config is `.gitleaks.toml` |
| CodeQL | `.github/workflows/codeql.yml` | `actions`, `javascript-typescript`, `python` |
| SDK drift | `.github/workflows/drift.yml` | Weekly run of type check, lint, tests and build against the newest `codemie-sdk` in range |

Before a PR, search your diff by hand for credentials, private hostnames, ticket keys and personal e-mail addresses.

## Commands that are not gates

Do not run `codemie-cdk deploy`, `codemie-cdk destroy`, `codemie-cdk backup`, `codemie-cdk import` or `codemie-cdk preview` for verification. They connect to a platform with the credentials in `.env`. See `.ai-run/guides/development/security-patterns.md`.

## Release

The release workflow is `.github/workflows/publish.yml`. Steps are in `docs/RELEASING.md`.
